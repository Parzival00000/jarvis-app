# JARVIS

JARVIS is a private assistant that runs on its owner's home server. It is not
a public service and has a single user: its owner.

## Privacy policy

- JARVIS reads the owner's Google Calendar through the Google Calendar API, only
  with the owner's consent, to show upcoming events in the owner's daily brief.
- It creates calendar events only after the owner approves each one.
- Calendar data stays on the owner's own server. It is not sold, shared with
  anyone, or used for advertising.
- The owner can revoke access at any time at
  https://myaccount.google.com/permissions

Contact: the owner of this GitHub account.
